# 청소년 스마트폰 사용과 스트레스

질병관리청 2025년 청소년건강행태조사의 공개 요약 통계를 사용한 학생용 데이터 시각화 프로젝트입니다.

## 질문

스마트폰을 많이 사용하는 학생일수록 스트레스도 높을까?

## 중요한 한계

질병관리청 공개 요약 통계에서 SNS만의 사용시간은 따로 제공되지 않아, 이 프로젝트는 SNS를 포함할 수 있는 전체 스마트폰 사용시간과 스트레스 인지율을 성별로 비교합니다. 따라서 개인별 SNS 사용량과 스트레스 사이의 관계나 원인·결과를 증명하지 않습니다.

개인 단위 분석을 하려면 질병관리청 [청소년건강행태조사 원시자료](https://www.kdca.go.kr/yhs/yhshmpg/main.do)를 공식 절차로 내려받고, 해당 사용시간 문항과 스트레스 문항을 교차분석해야 합니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

Python 그래프만 실행하려면:

```bash
python analysis.py
```

## 공식 출처

- [질병관리청 청소년건강행태조사](https://www.kdca.go.kr/yhs/yhshmpg/main.do)
- [제21차 2025년 원시자료 공개 안내](https://www.kdca.go.kr/bbs/kdca/42/304276/download.do)

2025년 공개 주요 수치:

- 평일 스마트폰 사용시간: 남학생 253.9분, 여학생 293.2분
- 스트레스 인지율: 남학생 32.9%, 여학생 50.3%
