# 청소년 스마트폰 사용과 스트레스 시각화

질병관리청 제21차(2025년) 청소년건강행태조사 자료를 사용한 학생용 Streamlit 시각화 앱입니다.

## 핵심 분석

2025년 원시자료에서 같은 학생의 스마트폰 사용시간과 스트레스 응답을 연결한 뒤, 스마트폰 사용시간 구간별로 ‘평상시 스트레스를 대단히 많이 또는 많이 느낀다’고 응답한 비율을 계산했습니다.

- 주중 1시간 미만: 높은 스트레스 비율 38.2%
- 주중 1~3시간: 36.2%
- 주중 3~5시간: 39.3%
- 주중 5~8시간: 44.1%
- 주중 8시간 이상: 52.4%

이 결과는 관계를 보여주는 탐색 결과이며, 스마트폰 사용이 스트레스의 원인이라고 단정하지 않습니다. 스트레스가 높은 학생이 스마트폰을 더 많이 사용하는 가능성도 있습니다.

## 앱 메뉴

- 핸드폰 사용-스트레스 관계: 주중·주말, 사용시간 구간, 성별·학교급·학년별 비교, 산점도
- 2025 성별 비교
- 2025 최신 추이
- 2025 학교급·성별
- 2020 서울 스트레스 원인 상세
- 2020 서울 학년·성별 비교
- 2015~2020 서울·전국 추이
- 2025 미디어 과의존

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```
